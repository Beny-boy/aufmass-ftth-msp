# Coding-Stil

- Folge den bestehenden Formatter-/Linter-Einstellungen und Namenskonventionen.
- Schreibe kleine, eindeutig verantwortliche Funktionen und Module.
- Verwende klare Namen; vermeide irreführende Abkürzungen und überflüssige Kommentare.
- Keine neuen Abhängigkeiten ohne nachvollziehbaren technischen Nutzen.
- Ergänze bei Änderungen vorhandene Typdefinitionen, Dokumentation und Fehlermeldungen.
- Achte auf Laufzeit, Speicherbedarf, Verständlichkeit, Barrierefreiheit und Sicherheit, wo relevant.
