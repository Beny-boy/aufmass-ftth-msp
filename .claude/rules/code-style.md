# Code-Style
- Bestehenden Stil in `index.html` übernehmen (Einrückung, Benennung), nicht umformatieren.
- Keine neuen externen Abhängigkeiten/CDNs: die App muss offline laufen.
- UI-Texte, Fehlermeldungen und Kommentare auf Deutsch.
- Keine Änderungen an eingebetteten Base64-Blöcken (Icons, Manifest) ohne ausdrücklichen Auftrag.
