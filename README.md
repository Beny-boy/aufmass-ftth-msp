## Projekt-Aufgaben (Desktop-Erinnerung) – Ordner `aufgaben/`
Excel-Tabelle (Projekt, Aufgabe, Fällig, Status, Priorität, Verantwortlich) importieren, Aufgaben nach Überfällig/Heute/7 Tage/Später sortiert, Desktop-Benachrichtigung zur gewählten Uhrzeit.
- Browser-Version: `aufgaben/index.html` öffnen (Erinnerung nur bei geöffnetem Browser).
- Desktop-App (Windows): läuft im Hintergrund im Infobereich und startet mit Windows, siehe `aufgaben/README.md`.
Excel-Bibliothek: SheetJS 0.18.5 (Apache-2.0, `aufgaben/xlsx.LICENSE.txt`).
